# Customer Backend

Folder dành cho thành viên phụ trách xử lý backend của khách hàng.

## Phạm Vi

- Đăng nhập và đăng ký khách hàng.
- Hồ sơ tài khoản khách hàng.
- Đặt lịch chăm sóc thú cưng.
- Xem dịch vụ, phụ kiện và đánh giá.
- Theo dõi lịch sử đặt lịch.

## Cấu Trúc

- `routes/`: endpoint dành cho khách hàng.
- `controllers/`: xử lý request/response khách hàng.
- `services/`: logic nghiệp vụ phía khách hàng.
- `models/`: dữ liệu liên quan tài khoản, đặt lịch và đánh giá.
