# Admin Backend

Folder dành cho thành viên phụ trách xử lý backend của admin.

## Phạm Vi

- Quản lý hệ thống.
- Quản lý tài khoản và phân quyền.
- Quản lý nhân viên.
- Xem báo cáo và thống kê.

## Cấu Trúc

- `routes/`: endpoint dành cho admin.
- `controllers/`: xử lý request/response admin.
- `services/`: logic nghiệp vụ admin.
- `models/`: dữ liệu liên quan admin.
