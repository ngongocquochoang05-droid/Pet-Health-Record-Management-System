# Staff Backend

Folder dành cho thành viên phụ trách xử lý backend của nhân viên cửa hàng.

## Phạm Vi

- Quản lý khách hàng tại cửa hàng.
- Quản lý lịch hẹn.
- Quản lý hồ sơ thú cưng.
- Đăng ký dịch vụ.
- Kiểm tra thanh toán.
- Quản lý sản phẩm.

## Cấu Trúc

- `routes/`: endpoint dành cho nhân viên.
- `controllers/`: xử lý request/response nhân viên.
- `services/`: logic nghiệp vụ vận hành cửa hàng.
- `models/`: dữ liệu liên quan lịch hẹn, thú cưng, thanh toán và sản phẩm.
